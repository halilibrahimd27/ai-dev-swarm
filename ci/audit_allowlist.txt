# uv 0.9.30 (dev-only) — fix lands in 0.11.6; the user-facing host uv is

GHSA-pjjw-68hj-v9mw

# fastapi 0.136.3 — MAL-2026-4750 has no upstream fix yet (Fix Versions
# column is empty). Our FastAPI is bound to 127.0.0.1 only (docker
# publish line is `127.0.0.1:8080:8080`; Settings._enforce_loopback
# refuses LAN IPs) so the attack surface is local-only. Revisit once
# upstream ships a fix.
MAL-2026-4750

# chromadb 1.1.1 — CVE-2026-45829 has no upstream fix yet (Fix Versions
# column is empty). chromadb is a transitive dep via CrewAI's internal
# short-term memory; we never feed it untrusted input nor expose its
# HTTP/gRPC surfaces (CrewAI uses the embedded path internally — we don't
# run a chromadb server). Revisit once upstream ships a fix.
CVE-2026-45829

# uv 0.9.30 (dev-only) — GHSA-4gg8-gxpx-9rph; fix lands in 0.11.15. Same

# used by GitHub Actions to read uv.lock; the user-facing host uv is
# already 0.11.16. No production exposure.
GHSA-4gg8-gxpx-9rph
